# Project Documentation

## Smart Infrastructure Maintenance Planning System

This document contains the initial project documentation for the proposed Smart Infrastructure Maintenance Planning System.

### Project Goal
To organize infrastructure maintenance information and prioritize maintenance tasks using suitable Data Structures and Algorithms.

### Core DSA
- Trees
- Graphs
- Binary Search Tree
- AVL Tree
- Binary Heap / Priority Queue
- Searching
- Sorting

### Month 1 Status
Problem understanding, requirements, stakeholder identification, initial literature review and DSA concept mapping have been completed.

Implementation is planned for subsequent reviews.
